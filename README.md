# Personal Portfolio Website

## 📌 Project Overview

This project is a simple **personal portfolio website** developed using **HTML5 and CSS3**. The website is designed to present basic information about me in a clean and simple layout.

The portfolio currently contains two main pages: a **Home page** and a **Contact page**. The Home page provides an introduction, while the Contact page allows visitors to find my contact details or get in touch with me.

🔗 **Live Website:** https://mangayarkarasipalraj.github.io/simple-portfolio-website/**

## 🌐 Pages Included

### 🏠 Home Page

The Home page is the main landing page of the portfolio. It provides an introduction and gives visitors an overview of the website.



## 🛠️ Technologies Used

* **HTML5** – Used to create the structure and content of the webpages.
* **CSS3** – Used to style the webpages, including colors, fonts, spacing, layout, and overall appearance.
